💡 The Core Unknowns Clarified

1. How Live Obstacle Placement Replans Without Stuttering

The robot moves discretely cell-by-cell at an animation cadence. When the user clicks a grid cell, the obstacle coordinates are registered in WarehouseWorld. If the coordinate lies in the robot's remaining path:

The simulation pauses the robot's next step, executes a synchronous astar.findPath() call from the robot's current cell (which takes under 0.5ms on a 16x12 grid), swaps out the remaining waypoints for the new detour, and resumes motion on the very next tick. Frame rate never drops and the animation loop stays completely smooth.

2. How the Dual Parser Falls Back Deterministically

missionParser.ts checks for the optional VITE_GEMINI_API_KEY. If absent or if the network fetch fails, it silently routes to fallbackParser.ts. The fallback parser uses deterministic regex keyword patterns to extract the target item, destination, and avoid rules into the exact same TypeScript schema. Tests pass 100% offline without network mocks.

🧩 Decoupled Software Components

Mission Parser src/parser/

Dual-mode: LLM extraction with instant keyword regex fallback. Returns strict validated MissionTask.

Implements PRD: 1. Mission Input & Parser

A* Pathfinder src/planner/astar.ts

Pure mathematical 4-directional pathfinder with Manhattan heuristic. Fully unit-tested with Vitest.

Implements PRD: 2. A* Pathfinding

Simulation & Robot src/sim/

Deterministic state machine (IDLE, MOVING, REPLANNING, ARRIVED, BLOCKED). Coordinates waypoints and rerouting.

Implements PRD: 3. Live Replanning

Canvas 2D View src/render/canvasRenderer.ts

Draws warehouse grid, docking bay, cargo items, green drop zones, hazard stripes, and glowing cyan paths.

Implements PRD: Screens and Layout

Telemetry Log src/ui/telemetryLog.ts

Real-time scrolling event feed with color-coded badges (INFO, PARSE, PLAN, WARN, REPLAN, SUCCESS, ERROR).

Implements PRD: 4. Explainability Log

Control Panel src/ui/controls.ts

Binds custom text input, preset buttons, 1x/2x speed selector, and reset button to the simulation manager.
