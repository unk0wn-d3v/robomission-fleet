📋 Concrete Acceptance Criteria

  • ✓
    Dual-Mode Extraction: Parses natural language into strict JSON: { action, item, destination, avoid, returnToDock }.
  • ✓
    Offline Fallback: Rule-based keyword/regex parser ensures presets and standard prompts run with 100% offline reliability.
  • ✓
    Graceful Invalid Handling: Inputs like "fly to the moon" are rejected, robot remains idle, input text is preserved, and a clarifying hint is logged.
  • ✓
    3 Preset Buttons: Preset 1 (Standard delivery), Preset 2 (Avoidance), Preset 3 (Multi-step with return to dock).
  • ✓
    Deterministic Manhattan A*: Calculates mathematically optimal shortest path across grid cells, avoiding boundaries and static walls.
  • ✓
    Cyan Vector Visualization: Overlay route renders smoothly across the grid before the robot moves.
  • ✓
    Dynamic Path Trimming: As the robot advances cell-by-cell, traversed path segments clear cleanly.
  • ✓
    Click-to-Drop Interaction: Clicking any empty grid cell during robot transit immediately drops a warning hazard (spill/rack).
  • ✓
    Instant Detection & Replan: If obstacle intersects the active trajectory, robot pauses, recalculates detour, updates cyan route line, and resumes.
  • ✓
    Interactive Toggle / Unblock: Clicking an existing obstacle removes it, enabling users to unblock walled paths.
  • ✓
    Real-Time Narration: Explains parsing results, path step counts, obstacle coordinates, replan reasoning, and goal delivery.
  • ✓
    Categorized Event Badges: Visual badges for INFO, PLAN, WARN, SUCCESS, and ERROR.
  • ✓
    Auto-Scroll: Keeps latest decision visible while preserving complete run history until Reset.

Ready State

Idle docked robot, stationary items, system ready log.

In-Transit State

Robot moving cell-by-cell, interactive click-to-drop enabled.

Replanning State

Brief pause, alternative A* route computed, route line updated.

Blocked / Trapped State

No valid path possible. Robot stops safely; log instructs user to clear obstacle or reset.

Reset Button

Halts movement, clears dynamic obstacles, resets robot and items to initial positions.

Speed Toggle (1x / 2x)

Allows normal human-readable speed (1x) or rapid demo verification (2x).
