RoboMission Fleet

Scope Companion & Core Loop Architecture

Scope: Approved

🎯 The Unique Kernel

Demystifying robot autonomy for beginners by connecting natural-language missions directly to deterministic A* pathfinding, real-time obstacle rerouting, and a live explainability log that shows autonomy as a series of understandable decisions.

🔄 The Interactive Core Loop

👤 Who It's For

Students and beginners exploring autonomous robotics and multi-agent systems.

Today's friction: Overwhelmed by complex Linux ROS stacks, abstract A* matrices, or static textbook figures.

Our solution: An instant-load browser sandbox where every instruction, calculation, and detour is immediately visible and explained.

🏁 What "Working" Looks Like (1-3 min Demo)

1
Preset Mission: Click example mission -> LLM/Fallback parses to structured JSON -> A* plots path.
2
Transit: Single robot follows the grid path smoothly with live telemetry.
3
The "Aha!" Moment: Drop obstacle directly on its path -> Robot halts -> Replans detour -> Log explains the choice.
4
Graceful Failure: Trap target behind walls -> System detects unreachable goal and clearly reports why.

📦 Scope Boundaries & Tradeoffs

  • NOW
    Single Autonomous Robot: Deterministic state machine (idle, navigating, carrying, replanning, arrived).
  • NOW
    2D Canvas Warehouse World: Clear grid cells, pickup locations, delivery bays, and static barriers.
  • NOW
    Deterministic A* Pathfinding: 4-directional shortest path algorithm with full unit test coverage.
  • NOW
    Dual Mission Parser: LLM prompt parser + strict JSON schema + offline rule-based fallback parser.
  • NOW
    Live Obstacle Drop & Replan: Click any cell to place a hazard; robot immediately re-evaluates route.
  • NOW
    Real-Time Explainability Log: Human-readable narration explaining decisions, detours, and failure states.
  • NOW
    Demo Controls: Reset button, 1x/2x speed controls, and 3 preset missions + 1 impossible case.
  • LATER
    Second Robot (Tier 3): Multi-agent fleet dispatching tasks simultaneously.
  • LATER
    Collision Avoidance & Yielding (Tier 3): Spatial-temporal reservation or robot-to-robot yield priority.
  • LATER
    Visual Search Frontier (Tier 4): Real-time animation of A* open/closed set node expansion.
  • LATER
    Third Robot & Layout Selector: Multi-floor layouts or dynamic warehouse size switching.
  • CUT
    Backend / Database / Cloud: Pure client-side browser app for 100% zero-setup portability.
  • CUT
    User Authentication & Profiles: Reviewers do not create accounts; frictionless access is essential.
  • CUT
    Continuous Physics & Kinematics: Discrete grid navigation avoids physics engine bugs and nondeterminism.
  • CUT
    ROS / ROS2 Integration: Out of scope for a fast, accessible browser learning proof of concept.
  • CUT
    Custom Map Drawing Editor: Preset layouts keep the demo predictable and fast to build.
